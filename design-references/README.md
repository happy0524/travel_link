# Local design references

이 이미지들은 내부 디자인 참고 자료다.
애플리케이션에서 직접 표시하지 않는다.
배포 파일에 포함하지 않는다.
이미지를 복제하거나 서비스 자산으로 사용하지 않는다.
Codex는 구현 전 이미지를 직접 열어 색상, 질감, 선 굵기와 시각적 위계를 분석할 수 있다.

## Map 2 — Leaf Node / Urban Veins

- 도시는 하나의 나뭇잎
- 도로와 골목은 잎맥
- 방문 장소는 노드
- `#86BAEA` 이동 경로는 잎맥을 따라 흐르는 물
- 사용자가 방문 순서를 변경하는 행위는 도시의 흐름을 다시 설계하는 것
- 손그림 표현은 객관적인 지도 위에 개인적인 여행 경험을 겹쳐 놓는다는 의미

대표 이미지: `map2-leaf-node-reference.jpg` (원본 `map2.jpg`).

## Map 3 — Watercolor City Map

- 밝은 종이색 육지
- 수채화처럼 표현된 파란 수역
- 검은 잉크 형태의 도로망
- 녹색 공원과 자연 영역
- 주요 도로와 골목의 강한 선 굵기 차이
- 손으로 채색한 여행 아틀라스 또는 도시 도면의 인상
- Google 기본 지오메트리는 유지하면서 지도 스타일, 종이 질감, 수채화 농도, 손그림 오버레이로 근사

대표 이미지: `map3-watercolor-city-reference.jpg` (원본 `map3.jpg`).
